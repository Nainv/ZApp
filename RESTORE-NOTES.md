# Zikra — restored main interface

The root `index.html` has been restored from the provided original full interface (232,562 bytes). This preserves the original UI rather than the image-overlay starter page.

Important: the six `cells/*/index.html` files in the supplied ZIP are mixed standalone pages/partials and are not yet safe to inject directly into the original DOM. This package does NOT pretend that they are fully integrated. The original interface remains functional as the root page; integrating each cell requires extracting its feature logic into modules and wiring those modules to existing elements without duplicating the UI.

VersionName / Downloader code are not changed by this edit.
