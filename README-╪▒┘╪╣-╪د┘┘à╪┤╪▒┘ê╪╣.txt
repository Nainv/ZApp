مشروع ذِكرى — تعليمات الرفع من Windows

1) أغلق أي نافذة تعديل مفتوحة على ملفات المشروع.
2) فك ضغط هذا الملف ZIP إلى مجلد مؤقت.
3) افتح المجلد الذي يحتوي index.html وcells وassets وملف .github.
4) افتح مجلد المستودع المحلي zikra-android-tv-new الذي استنسخته بواسطة GitHub Desktop.
5) انسخ محتويات المجلد المؤقت إلى جذر المستودع المحلي، واختر Replace/استبدال عند السؤال.
   انسخ المجلدات المخفية أيضاً، خصوصاً .github.
6) لا تحذف .git من المستودع المحلي ولا ترفع ملف ZIP نفسه.
7) افتح GitHub Desktop؛ راجع قائمة Changes. اكتب Summary: Rebuild Zikra modular UI
   ثم Commit to main ثم Push origin.
8) بعد الرفع افتح تبويب Actions في GitHub وتحقق من نتيجة بناء APK. لا تعتبر البناء ناجحاً إلا إذا ظهر Success.

ملاحظة: ملفات الخلايا الست مستقلة داخل cells/، والملفات المشتركة داخل assets/.
تم فحص صياغة ملفات JavaScript والتحقق من مراجع الملفات المحلية في HTML.
لم يتم اختبار APK على جهاز Android TV فعلي؛ وظائف الإنترنت تحتاج اتصالاً فعلياً.
