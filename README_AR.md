# ذِكرى — النسخة المصححة

- شريط الدعاء يتحرك من اليسار إلى اليمين، مع تغيير الدعاء دورياً.
- تحديد المدينة يستخدم OpenStreetMap Nominatim (قد يحتاج اتصال إنترنت وموافقة الموقع).
- مواقيت الصلاة تُجلب من AlAdhan API حسب إحداثيات الجهاز، ولا تستخدم إحداثيات إيرفورت كبديل.
- في نافذة القرآن يمكن اختيار القارئ والسورة والآية وتشغيل الآية المختارة، أو تشغيل آيات عشوائية.
- القراء المتاحون يعتمدون على توفر الملفات الصوتية لدى EveryAyah.
- أدهم نابلسي فنان وليس قارئ قرآن؛ لم أضعه ضمن قراء القرآن. يمكن إضافته لاحقاً في قسم منفصل للأناشيد إذا توفّر مصدر صوتي مناسب.

## النشر
ارفع `index.html` إلى جذر مستودع GitHub Pages واستبدل النسخة الموجودة، ثم انتظر انتهاء النشر.

## حدود الاختبار
تم فحص صياغة JavaScript فقط. يلزم اختبار تحديد الموقع والصوت فعلياً على الجهاز بعد النشر.
